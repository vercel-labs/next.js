# Reproduction: unused `blurDataURL` inflates the client bundle (vercel/next.js#54012)

Static image imports always emit a base64 `blurDataURL` into the client JS bundle, even
when `placeholder="blur"` is never used anywhere. It is not tree-shaken.

## Run

```bash
npm install
npm run build          # Turbopack (default)
npm run check
npm run build:webpack  # webpack
npm run check
```

`npm run check` scans `.next/static/chunks/**/*.js` for inlined `data:image/...;base64,` strings.
Fixture images (100 PNG icons + one large PNG) are generated by `generate-images.mjs` on `prebuild`.

## Pages

- `/icons` – imports 100 static PNG icons into a map, renders exactly one, no blur placeholder.
- `/photo` – one large PNG with `next/image`, no blur placeholder.

Note: the animated-image part of the original report is fixed – an animated GIF import now
produces `blurWidth: 0` and no data URL. The general "unused blurDataURL is still bundled"
problem remains in both bundlers.
